timAer
======

PowerShell time-keeping script with dialog boxes.

The output of the file is formatted in HTML. You need a working mail client with SMTP configured for the mailer executable (TimAerMailer.ps1) to work. The program also uses XML to store time and name variables for future entries.

To visualize sampleOutput.html file, you can run it in any HTML parser or browser.  You can test it at htmledit.squarefree.com.
